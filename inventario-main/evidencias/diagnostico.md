1.Explique la diferencia entre java y javac.
  El comando javac compila el código fuente en texto (.java) a un archivo de bytecode (.class), mientras que el comando java ejecuta ese bytecode ya traducido en la Máquina Virtual de Java. En resumen, javac crea el programa y java lo pone a marchar

2.Explique qué función cumple Git.
  Es un sistema de control de versiones distribuido que permite registrar cambios en el código, volver a versiones anteriores y trabajar colaborativamente.
  
3.Explique si Git y GitHub son lo mismo.
  Git es la herramienta local de control de versiones. GitHub es una plataforma en la nube que aloja repositorios de Git para almacenarlos o compartirlos.

4.Defina repositorio, API y método HTTP GET.
  Repositorio: Carpeta o espacio donde se almacena el código del proyecto junto con todo su historial de cambios.

  API: Interfaz de programación de aplicaciones; conjunto de definiciones y protocolos que permite a dos sistemas comunicarse.

  Método HTTP GET: Método utilizado exclusivamente para solicitar o consultar datos de un servidor sin modificar nada.
