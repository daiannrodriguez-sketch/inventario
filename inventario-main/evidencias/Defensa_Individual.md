Defensa individual
¿Qué problema resuelve Spring Boot?

Elimina la configuración manual compleja (XML/código extenso) necesaria en Spring tradicional, permitiendo crear aplicaciones Java listas para producción de forma rápida con Tomcat embebido y dependencias preconfiguradas (starters).

¿Qué es una API?

Una interfaz que permite que dos sistemas o aplicaciones de software diferentes se comuniquen e intercambien datos entre sí de manera estructurada.

¿Qué es un endpoint?

Una URL específica expuesta por un servidor a la que un cliente (como Angular o el navegador) hace peticiones para acceder a un recurso o servicio.

¿Qué hace un Controller?

Es la clase encargada de recibir las peticiones HTTP del cliente, procesarlas (interactuando con la lógica o servicios) y retornar la respuesta adecuada.

¿Qué diferencia existe entre Java y Spring Boot?

Java es el lenguaje de programación base. Spring Boot es un framework (marco de trabajo) construido sobre Java para facilitar la creación de aplicaciones web y microservicios.

¿Qué es JSON?

(JavaScript Object Notation). Es un formato de texto ligero y universal utilizado para intercambiar datos entre el servidor y el cliente mediante pares clave-valor.

¿Qué significa serializar?

Convertir un objeto Java en memoria a una cadena de texto plana (como JSON) para que pueda enviarse a través de la red.

¿Qué significa GET?

Es un método del protocolo HTTP utilizado exclusivamente para solicitar y consultar información desde el servidor, sin modificar la base de datos.

¿Qué función cumple Git?

Es un sistema de control de versiones distribuido que rastrea, registra y gestiona los cambios realizados en el código fuente de un proyecto a lo largo del tiempo.

¿Qué diferencia existe entre Git y GitHub?

Git es la herramienta que se ejecuta localmente en tu computadora para controlar el historial del código. GitHub es una plataforma en la nube para alojar repositorios de Git y colaborar en línea.

¿Qué es un commit?

Es una captura o "instantánea" guardada localmente de los cambios realizados en el código, acompañada de un mensaje descriptivo.

¿Qué hace git push?

Sube y sincroniza los commits locales guardados en la computadora hacia el repositorio remoto (como GitHub).

¿Qué significa origin?

Es el nombre por defecto o alias que Git le asigna al repositorio remoto configurado en la nube.

¿Qué significa main?

Es el nombre de la rama principal del proyecto donde reside el código estable e integrador.
